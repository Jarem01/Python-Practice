Create an exercise

  1. Fill in the form — the JSON updates as you type and problems are listed before you save.
  2. Save draft keeps it in this browser only, so you can try it in the list immediately.
  3. Download .json and put the file in the problems/ folder of the repository.
  4. Run python3 tools/build_index.py so the exercise becomes part of the committed bundle.

Format notes

  • prompt, hints and definitions accept Markdown; glossary terms are linked automatically.
  • starter_code for fill-in-the-blank uses ___ (three or more underscores) as the blank marker.
  • expected_output is compared printing-by-printing, ignoring trailing spaces and blank lines.
  • tests is Python appended after the learner's code: it must assert what you want to check.
  • setup is Python that runs before the learner's code (sample data, imports, fixtures).
  • List extra packages in packages (for example numpy, pandas) to have them loaded on demand.
  • Use glossary slugs such as for-loop, dictionary, axis to link to the glossary page.
