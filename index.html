Learning content

The course in order — Intro 1–4, then Data Analysis 1–6 — with the exercises found inside each section. Run opens a notebook as a live, editable notebook in the browser (like Jupyter), with every exercise inside it boxed so you can jump straight to the one you want.

Extending the system

Add course material

Drop notebooks (.ipynb), scripts (.py) and data files on the Add material page: they are analyzed in your browser, stored in the materials/ folder of the repository, and turned into practice exercises automatically.

Add an exercise

Use the creator form to build one in the browser, then drop the downloaded JSON into problems/. Drafts are kept in your browser so you can try them right away.

Add anything else

Copy files into the repository by hand and run python3 tools/build_index.py. The index, the exercises list and the topic links are all regenerated from your files, whether they arrived from this page or from Git.

Read the README for the full workflow, the problem format and how to publish on GitHub Pages.
