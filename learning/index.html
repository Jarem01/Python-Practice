Learning content

The class you picked in the header, in its own order, with the exercises found inside each section. Every notebook opens as a live notebook: each cell can be edited and run in your browser, exactly like Jupyter, and the exercises inside it are boxed so you can find them.

Topics and how they map to exercises

A notebook is matched to a topic when the topic name (or a word of it) appears in the notebook's title, path or markdown. Override any notebook's title, label, group, order, topics or data files in data/curriculum.json, then re-run python3 tools/build_index.py.

Notebooks come straight from the repository. Running one never changes the file; your edits stay in this browser only.
