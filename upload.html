Upload course material

Drop in notebooks (.ipynb), scripts (.py) and their data files (.csv, .xlsx, …). Everything is analyzed in your browser: titles, cell counts, the exercises inside each notebook, and — for notebooks — the printed output of every solution, which becomes an automatically checked practice exercise.

Files are committed to the folder you choose below. It starts as materials/; a class that keeps its material in its own folder (FIN 400 → fin400/) starts there instead. Add files as often as you like, and the learning and practice pages pick them up as soon as the index is rebuilt.

  1. Add files by dropping them below or picking them from your computer.
  2. Analyze to see what was detected and to build practice exercises.
  3. Save to GitHub (the source files land in the folder you chose) or to this browser, then keep browsing — uploads show up in the learning and practice sections right away.

Answer keys and model solutions belong in fin400/solutions/. The site never publishes that folder: the build leaves its files out of the index and tools/assemble_site.py removes it from the published site, so no page links to a solution. The files do stay in the repository, and a public GitHub repository shows them to anyone who browses there — keep the repository private (or keep answer keys off GitHub) if students must not see them.

GitHub settings

Saving to GitHub commits each file to materials/ with the GitHub API. The token stays in this browser (localStorage) and is sent only to api.github.com. Use a fine-grained token with Contents: Read and write for this repository, or a classic token with the repo scope. Nothing is committed until you click Save to GitHub.

keep the token in this browser

No token? Use the bundle + importer instead

Click Download bundle for the importer, then in your clone of the repository:

python3 tools/import_materials.py ~/Downloads/materials-bundle.json
python3 tools/build_index.py
git add -A && git commit -m "Add course material" && git push

Uploads are analyzed locally; nothing is sent anywhere except the GitHub API when you ask for it.
